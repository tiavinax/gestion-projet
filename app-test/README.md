# Projet Servlet: web

## Structure du projet:
```
web/
├── src/main/java/web.java
├── src/main/webapp/
│   ├── WEB-INF/web.xml
│   └── index.html
├── lib/
│   └── servlet-api.jar
├── build/
├── deploy.sh
└── README.md
```

## Pour compiler et déployer:

1. cd web
2. ./deploy.sh

## Accès:
- Page d'accueil: http://localhost:8080/web/
- Servlet: http://localhost:8080/web/
